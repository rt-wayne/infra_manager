# 第 124 項：登入改用外部驗證 API（WPX VerifySecure）＋人員資料改讀 PX_SYNC_EMP

> 狀態：施工中（2026-10-20 起）。方向與設計題（①～⑭、D0～D12、E1～E8）已拍板，階段 0 查證已完成。
> 目前進度見下方「階段清單」狀態欄與 BACKLOG 交接欄。
> 討論日期：2026-10-19～2026-10-20（使用者與 Claude 主對話；D 題、E 題與階段計畫由 architect 2026-10-20 分析）

## 目標

- 登入不再比對本系統的密碼雜湊，改為把工號＋密碼交給 WPX 的 VerifySecure 登入 API 驗證；成功後仍由本系統發自己的登入憑證（token），之後的權限、切換身分、登出都不變
- 長期方向（使用者 2026-10-20）：**不在本系統資料庫維護使用者帳號**，人員姓名、Email、部門改讀公司同步表 `PX_SYNC_EMP`（擁有者 RD_USER，已有 PUBLIC 別名）
